# Commit Types

- `feat` is used for new features.
- `fix` is used for bug fixes.
- `docs` is used for documentation changes.
- `refactor` is used for code changes that neither fix a bug nor add a feature.
- `test` is used for adding missing tests or correcting existing tests.
- `style` is used for code style changes (white-space, formatting, missing semicolons, etc; no production code change).
- `perf` is used for code changes that improve performance.
- `build` is used for changes that affect the build system or external dependencies (e.g. gulp, webpack, npm).
- `ci` is used for changes to CI configuration files and scripts (e.g. GitHub Actions, Travis, CircleCI).
- `chore` is used for other maintenance changes that don't modify source or test files (e.g. tooling config, repo housekeeping).
- `revert` is used for reverting a previous commit.
