# User Story 範例（對齊粒度用）

以下三個 User Story 刻意選了不同形態：異動型（有狀態與優先序）、檢視型（無狀態）、
審核型（狀態互斥、依金額分流）。共通點：需求來源可追溯，規則每條都看得出會變成什麼畫面行為，
範圍寫了不涵蓋，驗收條件可直接拿來核對 mockup。
條數、欄位有無與業務領域只是示意，依實際需求決定，不必比照。

### US-02 新增填答人員

| As a ... | I want to... | so that... |
| :---- | :---- | :---- |
| 管理者 | 為已定版評估新增填答人員並設期限 | 讓評估能分派給更多人完成 |

- **需求來源**：2026-09-15 需求訪談紀錄；SRS 3.2.4
- **定位**：管理者在已定版的治理評估中加入新的填答人員，使評估能分派給更多人完成。
- **角色與入口**：管理者；從「評估指派」頁的評估明細，點「新增人員」。
- **規則**：
  - 只有「已定版」且未送出分析的評估可新增人員
  - 同一評估不可重複指派同一人，已指派者在選單中反灰
  - 新增時必須指定填答期限，期限須為今天或之後
  - 新增後該人員狀態為「未開始」，進度 0%
  - 評估整體進度＝所有人員已回答題數總和 ÷（人數 × 題數）
- **狀態**：人員填答狀態：未開始 → 填答中 → 已完成；期限已過且未完成為「已逾期」。
  顯示優先序：已完成 > 已逾期 > 填答中 > 未開始。
- **範圍**：
  - 涵蓋：從既有使用者清單挑選、設定期限、新增後即時更新列表與整體進度
  - 不涵蓋：建立新使用者帳號、修改既有人員期限、批次匯入
- **邊界情況**：
  - 評估已進入分析／審核／完成階段：隱藏「新增人員」按鈕並顯示鎖定提示
  - 可選人員清單為空：顯示空狀態與「前往使用者管理」連結
- **驗收條件**：
  - Given 評估已定版且未送出 / When 管理者選擇未指派的人員並設定明日為期限 / Then 列表新增該人員，狀態「未開始」，整體進度重新計算
  - Given 評估已送出分析 / When 管理者進入該評估明細 / Then 看不到「新增人員」按鈕，並看到鎖定提示
  - Given 選擇的期限早於今天 / When 送出 / Then 顯示期限錯誤，不新增

### US-01 查詢對話紀錄

| As a ... | I want to... | so that... |
| :---- | :---- | :---- |
| 客服主管 | 依日期與客戶查詢對話紀錄 | 處理客訴時能找到原始對話 |

- **需求來源**：2026-08-20 需求訪談紀錄；RFP 4.1
- **定位**：客服主管在處理客訴時，找出客戶與智能客服的原始對話作為依據。
- **角色與入口**：客服主管；從「客服管理 > 對話紀錄」進入。
- **規則**：
  - 預設顯示近 7 天紀錄，依開始時間新到舊排序
  - 可依日期區間、客戶帳號、關鍵字篩選，條件可併用
  - 日期區間最長 90 天，超過時查詢按鈕不可按
  - 客戶手機號碼在列表中遮蔽中間四碼
- **狀態**：無
- **範圍**：
  - 涵蓋：列表查詢、篩選、分頁
  - 不涵蓋：對話內容明細（另立 US）、匯出、修改對話
- **邊界情況**：
  - 查無資料：顯示空狀態與「清除篩選」
- **驗收條件**：
  - Given 近 7 天有對話 / When 主管進入對話紀錄頁 / Then 看到近 7 天紀錄，最新的在最上方
  - Given 選了超過 90 天的區間 / When 準備查詢 / Then 查詢按鈕不可按，並提示區間上限

### US-05 審核退貨申請

| As a ... | I want to... | so that... |
| :---- | :---- | :---- |
| 門市主管 | 核准或駁回店員送出的退貨申請 | 讓符合規定的退貨能及時退款 |

- **需求來源**：CR-014（2026-10-02 核准）
- **定位**：門市主管審核店員送出的退貨申請，決定是否進入退款。
- **角色與入口**：門市主管；從首頁「待審核」卡片或「退貨管理」列表點申請單。
- **規則**：
  - 只看得到自己門市的申請
  - 駁回必須填寫理由，理由會顯示給送件店員
  - 金額超過 NT$10,000 時，「核准」按鈕改為「送區經理覆核」
- **狀態**：退貨申請：待審核 → 已核准／已駁回／區經理覆核中。狀態互斥，不需優先序。
- **範圍**：
  - 涵蓋：單筆審核、填寫駁回理由
  - 不涵蓋：批次審核、區經理覆核畫面、退款執行
- **驗收條件**：
  - Given 一筆 NT$3,000 的待審核申請 / When 主管按核准 / Then 狀態變「已核准」，從待審核卡片消失
  - Given 主管按駁回但未填理由 / When 送出 / Then 顯示必填提示，狀態不變
  - Given 一筆 NT$12,000 的待審核申請 / When 主管開啟 / Then 只看到「送區經理覆核」與「駁回」
